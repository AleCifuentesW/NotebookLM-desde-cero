# Contribuir a este repositorio

Gracias por querer aportar. La idea de este repositorio es mantener prompts útiles, claros y amables para personas que están comenzando con NotebookLM.

## Cómo proponer nuevos prompts

1. Escribe el prompt en español claro y directo.
2. Indica cuándo usarlo (contexto breve).
3. Evita tecnicismos innecesarios.
4. No prometas resultados perfectos.
5. Incluye enfoque de verificación: sugiere revisar citas y datos importantes.

## Formato recomendado

- Título breve del prompt.
- Cuándo usarlo.
- Prompt listo para copiar.
- Consejo de uso (opcional, pero recomendado).

## Criterios de calidad

- Debe ser comprensible para principiantes.
- Debe mantener tono respetuoso, cercano y profesional.
- Debe favorecer aprendizaje práctico y organizado.
- Debe fomentar pensamiento crítico y revisión de información.

## Antes de enviar cambios

- Revisa ortografía y claridad.
- Verifica que el prompt no genere expectativas irreales.
- Mantén consistencia con el estilo del repositorio.
