# 05. Psicología del color

## ¿Cuándo usar este archivo?

Úsalo al diseñar materiales educativos cuando quieras comunicar mejor emociones, foco y legibilidad.

## Prompts listos para copiar

1. "Sugiere una paleta de colores para un material que busque calma y concentración. Incluye color principal, secundario y de apoyo."
2. "Propón una paleta para claridad y orden visual en una guía de estudio. Explica por qué funciona."
3. "Dame una paleta para transmitir confianza en una presentación educativa, con recomendaciones de contraste."
4. "Diseña una paleta para creatividad sin perder legibilidad en estudiantes principiantes."
5. "Sugiere colores para alertas y puntos importantes sin saturar el material."
6. "Evalúa esta combinación de colores y dime si es adecuada para aprendizaje prolongado."

## Consejo de uso

Mantén máximo 2 o 3 colores principales, evita saturar, y usa rojo solo para alertas o énfasis puntuales.

## Variación más simple

"Dame una paleta simple (2 o 3 colores) para un material educativo claro y agradable."
